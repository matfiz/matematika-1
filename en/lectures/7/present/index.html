Lecture 7

Continuous functions and the derivative

Continuity on a closed interval controls the whole set of function values. We prove that the largest and smallest values are attained and that a continuous strictly monotone function has a continuous inverse. A derivative then describes the local change of a function by one linear term. We distinguish this stronger property from continuity.

Uses.

  • Summary 2: A nonempty bounded-above real set has a supremum. An injective function has an inverse on its image.

  • Summary 3: Convergent real sequences are bounded and have unique limits.

  • Summary 4: Every bounded real sequence has a convergent subsequence. Closed-interval bounds survive a limit.

  • Summary 5: Continuity is relative to a domain and preserves sequence limits. Function limits obey the arithmetic laws and are locally bounded.

  • Summary 6: A continuous image of a real interval is an interval. The standard elementary limits are available without differentiation.

7.1 Extreme values on a closed interval

For a real function f:A→Rf:A\to\Rf:A→R, a global maximum is a value f(c)f(c)f(c) with c∈Ac\in Ac∈A such that f(x)≤f(c)f(x)\leq f(c)f(x)≤f(c) for every x∈Ax\in Ax∈A. 7.2 Continuity of an inverse

Recall from Lecture 6 that a real function on an interval is strictly increasing if x<yx<yx<y implies f(x)<f(y)f(x)<f(y)f(x)<f(y). It is strictly decreasing if these output inequalities are reversed. Either property is called strict monotonicity. It implies injectivity, so the inverse on the image exists. Non-strict monotonicity would permit constant pieces and would not supply an inverse.

7.4 One-sided derivatives and continuity

The right derivative uses the same quotient with h→0+h\to0+h→0+. The left derivative uses h→0−h\to0-h→0−. At an interior point, the derivative exists exactly when both one-sided derivatives exist and agree. Indeed, a two-sided limit has those restrictions. Conversely, the smaller of the two radii for a common requested error controls the full deleted neighbourhood. At an included endpoint of an interval domain, the same one-sided definition uses only the available side.

For example, the function f(x)=∣x∣f(x)=|x|f(x)=∣x∣ has quotient ∣h∣/h|h|/h∣h∣/h at zero. It equals 1 for h>0h>0h>0 and −1-1−1 for h<0h<0h<0. Summary

  • Theorem 7.1: a continuous real function on a closed bounded interval is bounded and attains both extreme values.
  • Theorem 7.2: a continuous strictly monotone function on a real interval has an interval image and a continuous inverse on that image.
  • Definition 7.3: a derivative is a finite limit of difference quotients. At an interior point, the two one-sided derivatives must agree.
  • Proposition 7.5: differentiability implies continuity. The converse fails for ∣x∣|x|∣x∣ at zero.
  • Proposition 7.6: differentiability is equivalent to a linear approximation with remainder o(h)o(h)o(h). The differential is the linear part.
