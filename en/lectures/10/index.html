Lecture 10

L’Hôpital and the shape of a graph

What this lecture does

Cauchy’s theorem compares changes in two functions. It proves a rule for zero-over-zero limits. Derivative signs then locate extrema and describe convexity. We combine these tests with domain and asymptote calculations in one graph investigation, and use them to choose the dimensions of a box.

10.3 Tests for local extrema

A critical number is an interior domain input where a function’s derivative is zero or does not exist. Fermat’s theorem puts every interior local extremum among these candidates. Domain endpoints must be checked separately in a global optimisation. A point outside the domain is not a critical number. An input ccc with f′(c)=0f'(c)=0f′(c)=0 is called stationary.

A strict local maximum requires f(x)<f(c)f(x)<f(c)f(x)<f(c) at all nearby domain points other than ccc. Strict local minima use the reverse inequality.

Proposition 10.3 (First-derivative test). Suppose fff is continuous at an interior input ccc and differentiable in a deleted neighbourhood. If f′>0f'>0f′>0 just to the left and f′<0f'<0f′<0 just to the right, then ccc is a strict local maximum. Reversing these signs gives a strict local minimum. If both signs are positive, or both negative, there is no local extremum at ccc.

Proof. In the maximum case, choose x<c<yx<c<yx<c<y close enough for the sign assumptions. The mean value theorem on [x,c][x,c][x,c] gives f(c)−f(x)>0f(c)-f(x)>0f(c)−f(x)>0. On [c,y][c,y][c,y] it gives f(y)−f(c)<0f(y)-f(c)<0f(y)−f(c)<0. Thus all nearby distinct values are below f(c)f(c)f(c). Apply this result to −f-f−f for the minimum case. If both signs are positive, the same reasoning gives f(x)<f(c)<f(y)f(x)<f(c)<f(y)f(x)<f(c)<f(y), ruling out either extremum. Negative signs reverse both comparisons and give the same exclusion. 

For example, a positive-to-negative derivative change gives more than the equation f′(c)=0f'(c)=0f′(c)=0: it compares the actual surrounding values. The test can also apply to a corner where f′(c)f'(c)f′(c) does not exist.

10.4 Convexity from derivative signs

Definition 10.5 (Convexity and concavity). A real function fff on an interval III is convex if f((1−t)x+ty)≤(1−t)f(x)+tf(y)(x,y∈I, 0≤t≤1).f((1-t)x+ty)\leq(1-t)f(x)+tf(y) \qquad(x,y\in I,\ 0\leq t\leq1).f((1−t)x+ty)≤(1−t)f(x)+tf(y)(x,y∈I, 0≤t≤1). It is concave if these inequalities are reversed.

The convex inequality says that the graph lies at or below each endpoint secant. A differentiable convex function has slopes that do not decrease. The following result makes this precise.

Summary

  • Theorem 10.1: Cauchy’s mean value identity compares two function changes. Its ratio form requires a nonvanishing denominator derivative.
  • Theorem 10.2: the one-sided zero-over-zero rule is proved. The infinity-over-infinity form is cited. Each requires its own limiting form and an existing derivative-ratio limit.
  • Propositions 10.3 and 10.4: derivative sign changes test local extrema. A nonzero second derivative at a stationary point also decides its type. A zero second derivative alone does not decide it.
  • Theorem 10.6: a differentiable function is convex on an open interval exactly when its derivative is nondecreasing. For twice differentiable functions, this is equivalent to a nonnegative second derivative.
  • A graph investigation keeps domain exclusions, asymptotes, derivative signs and convexity distinct. Optimisation also checks physical restrictions and boundary values before choosing among critical numbers.
